# Login Screen Project

## 概要
Next.js と Tailwind CSS を使用して作成した、  
**ログイン画面のUI（見た目のみ）を想定したサンプルプロジェクト**です。

実際の認証処理やバックエンド連携は行わず、  
フロントエンドのUI設計・スタイリングに重点を置いて実装しています。

---

## 使用技術
- Next.js 16（App Router）
- React 19
- TypeScript
- Tailwind CSS 4

---

## 実装のポイント
- グリーン × ブラックを基調とした、金融系サービスを意識したデザイン
- Tailwind CSS を用いた高速なUI構築
- フォーカス時にアイコンの色が変化する入力フォーム（`peer` 使用）
- 「Remember Me」を独立したコンポーネントとして分離し、状態管理を実装
- hover / transition を活用し、操作感を意識したUI調整
